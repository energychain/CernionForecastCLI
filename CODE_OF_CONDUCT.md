# Code of Conduct

This project follows a simple contributor covenant: be respectful, constructive and safety-minded.

## Expected behavior

- Use welcoming and professional language.
- Focus criticism on code, documentation and reproducible behavior.
- Respect different levels of energy-market, Python and CLI experience.
- Redact sensitive operational data before sharing examples.
- Help maintain a safe environment for contributors and users.

## Unacceptable behavior

- Harassment, threats or personal attacks.
- Publishing private information, credentials, customer data or non-public market communication payloads.
- Repeatedly ignoring maintainer requests about safety, scope or data redaction.
- Disruptive comments that do not help resolve the technical issue.

## Enforcement

Maintainers may edit or remove comments, close issues, block users or take other reasonable steps to protect the project and its users.

Security-sensitive data disclosures may be removed without prior discussion.
